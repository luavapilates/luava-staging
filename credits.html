So funktioniert's

Credits in drei Sätzen.

1. Konto erstellen

Jede Person bekommt ein eigenes Kundenkonto. Credits können nicht zwischen Personen geteilt werden.

2. Paket kaufen

Online mit Kreditkarte, PayPal, Apple Pay oder Google Pay. Alternativ im Studio bar oder per Karte.

3. Class buchen

Bei einer regulären Buchung werden automatisch 3 Credits von deinem Konto abgezogen.

4. Flexibel bleiben

Rechtzeitig stornierte Classes geben die Credits wieder frei. Es gibt keine monatliche Mitgliedschaft.
